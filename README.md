Discord Bot for Accessing Recent Game Data Sets
This Discord bot is designed to provide users with quick access to recent data sets related to a specific game. It features 5+ custom commands that allow users to retrieve, view, and interact with game-related data directly within Discord.

Features
Custom Commands: The bot supports 5+ custom commands to fetch and display game data.

Recent Data Sets: Provides access to the most up-to-date game data, including statistics, leaderboards, and more.

User-Friendly: Easy-to-use commands for seamless interaction.

Customizable: The bot can be extended with additional commands or data sources as needed.
